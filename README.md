This is a static recompilation of the arcade game Joust to the Nintendo DS. This is one of my favorite games, and there is no ideal way to play it on the DS. The port to the GBA is poor. GBC emulation is probably the best bet with the 7800 port being respectable.

This originally started as an attempt at an emulator. It ran fine but required a DSi CPU and experienced slowdown in later stages. This is a second attempt from the synamaxmusic reworked source code. It plays at full speed in both DS and DSi mode. This has been tested exclusively on hardware (DSi with TWiLight Menu++).

https://github.com/synamaxmusic/joust

The Mame (Joust Green) rom are required to be unzipped in /roms/joust. It will not boot without them. No infringement is intended.

Features:

Full screen scaling to fit the DS resolution

Fonts are reworked for readability as well

High scoring and user preferences saved to SD

Fun stuff:

Replaceable background images stored in /roms/joust similar to the Xbox 360 port

Muteable public domain chiptune music from the composer Drozerix. These are also replaceable with .mod/.xm files

An infinite lives toggle for those newer to the game. This disables high scoring

Swappable color palettes for our hero

I've done about 100 iterations played exclusively on real hardware. I know AI can be obnoxious. I am a Joust enthusiast who has played the game many times on real hardware. I am very familiar with how it should play and feel. If you encounter any issues let me know and I'll take a look.

I also have a GBA port. It runs at mostly full speed with an occasional dip. I may end up refining this as well.
